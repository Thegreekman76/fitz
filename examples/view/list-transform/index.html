Fitz list transform — Phase 11.7 R3.5a.1 smoke

An App.fitzv component compiled to WebAssembly that transforms a List<Int> entirely client-side. double all runs nums = nums.map(fn(n) => n * 2), keep over 5 runs nums = nums.filter(fn(n) => n > 5), and the "big ones" list is recomputed in the template with {#for m in nums.filter(...)} — a {#for} over the RESULT of a call, not just a bare state field.

No server round-trip: every button rewrites the list in the browser and re-renders. This is the expression machinery (closures, .map/.filter/.len, list reassignment) that the kanban SPA port needs on top of the nominal types from R3.

If you see this text but no widget above, the WASM bundle failed to load (check the DevTools console) or the page was opened over file://. ES modules require an HTTP origin — serve with python -m http.server 8000.
