Fitz click payload — Phase 11.7 R3.5b.1 smoke

An App.fitzv component compiled to WebAssembly that carries per-item data on a click via a data-flv-value-* attribute and reads it back through payload in the handler — the same data-flv-* convention the SSR runtime uses, so one .fitzv targets both.

Each button is <button data-flv-click="pick" data-flv-value-val="{n}">; the handler is if (payload.has("val")) { last = payload["val"] }. Click a number and watch "last picked" update.

If you see this text but no widget above, the WASM bundle failed to load (check the DevTools console) or the page was opened over file://. ES modules require an HTTP origin — serve with python -m http.server 8000.
