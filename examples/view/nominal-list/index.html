Fitz nominal list — Phase 11.7 R3 smoke

An App.fitzv component compiled to WebAssembly that iterates a List<Card> state field with {#for c in cards} and fans each nominal item's fields out into a keyed <CardRow key="{c.id}" title="{c.title}" />. Card is an imported classic type (from the sibling card.fitz) whose Rust struct the emitter synthesises inline.

Click Add task to push a fresh Card onto the list (live list mutation → reconciliation). Tap a row's counter, add another task, and watch the existing rows' counters survive — each card id keys a cached CardRow instance.

If you see this text but no widget above, the WASM bundle failed to load (check the DevTools console) or the page was opened over file://. ES modules require an HTTP origin — serve with python -m http.server 8000.
