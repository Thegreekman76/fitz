Fitz event bubbling — Phase 11.7.c smoke

Three <Item @choose="on_pick" /> children compiled to WebAssembly. Clicking any item fires its choose event, which bubbles to the parent's on_pick handler — props go down, events bubble up.

MVP limit: the bubble carries no payload, so the parent just counts clicks (it can't tell which item fired). Payload bubbling is a later slice.
