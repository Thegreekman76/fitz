Fitz multi-component showcase — Phase 11.5.e smoke

A Dashboard.fitzv with a Board root component composing three <MetricCard title="X" value="N" trend="Y" /> children. Static props coerce through the checker; each child gets its own __fitz-child-MetricCard wrapper in the DOM. Click any card's button to see the child's internal state mutate — the composition wiring does not propagate state up to the parent (that's 11.6+ event bubbling work), but children retain their own state between their own re-renders.
