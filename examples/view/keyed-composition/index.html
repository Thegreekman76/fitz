An App.fitzv component compiled to WebAssembly that mounts a <Column key="{name}" /> inside a {#for name in columns} loop over a List<Str> state field. Each column keeps its own taps counter. Tap a column, then re-render the parent — the counters survive because each key maps to a cached instance (keyed instance cache + reconciliation).
