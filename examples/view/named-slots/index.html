Fitz named slots — v0.24.0 smoke

A child Card lays out three holes: <slot name="title" />, a default <slot />, and <slot name="actions" />. The first card fills all three (its footer like button uses parent state and a parent handler, so it updates reactively). The second card fills only the title, so the body and actions show the child's fallback content.
