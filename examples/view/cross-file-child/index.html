Fitz cross-file <Child /> — Phase 11.7 smoke

An App.fitzv component compiled to WebAssembly that composes a <Card /> declared in a SEPARATE .fitzv file (Card.fitzv), imported with from Card import Card. Props flow down (title="..."), the child's like event bubbles up (@like="bump"), and slots — default + a named badge, each with a fallback — inject content rendered in the parent's scope.

Tap a card's ♥: its own like counter goes up, and the shared Total likes at the top increments too (the event bubbles cross-file to the parent). The first card fills both slots; the second fills only the body, so the badge shows its fallback.

If you see this text but no widget above, the WASM bundle failed to load (check the DevTools console) or the page was opened over file://. ES modules require an HTTP origin — serve with python -m http.server 8000.
