Fitz cross-file — transitive + alias (v0.26.0)

An App.fitzv compiled to WebAssembly that composes a <Row /> — the alias for a Card component imported with from Card import Card as Row. Card in turn composes a <Badge /> that lives in a THIRD file (Badge.fitzv) which App never imports: the transitive import walk discovers and inlines it.

Tap a card's ♥: its own like counter goes up and the shared Cards liked total at the top increments (the like event bubbles across the file boundary through the alias). Each card shows a small peak badge from the transitively-reached Badge.

If you see this text but no widget above, the WASM bundle failed to load (check the DevTools console) or the page was opened over file://. ES modules require an HTTP origin — serve with python -m http.server 8000.
