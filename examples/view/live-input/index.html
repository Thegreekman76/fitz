Fitz live value binding — CW.9 smoke

A LiveInput.fitzv component compiled to WebAssembly. The <select> fires @change and the text <input> fires @input; each handler reads payload["value"] and writes it to state — the same data-flv-<event> convention the SSR runtime reads, so one .fitzv targets both.

If you see this text but no widget above, the WASM bundle failed to load (check the DevTools console) or the page was opened over file://. ES modules require an HTTP origin — serve with python -m http.server 8000.
