Fitz conditional boolean attributes — gotcha #6

A ToggleForm.fitzv component compiled to WebAssembly. disabled={name == ""} on the Submit button and checked={name == ""} on the checkbox are present in the DOM iff the expression is truthy. Type into the field and both toggle reactively (the emitter set_attribute / remove_attribute in place); clear it and they come back — no {#if} two-variant workaround needed.

If you see this text but no widget above, the WASM bundle failed to load (check the DevTools console) or the page was opened over file://. ES modules require an HTTP origin — serve with python -m http.server 8000.
