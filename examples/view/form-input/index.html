Fitz form payload — Phase 11.7 R3.5b.2 smoke

An App.fitzv component compiled to WebAssembly that reads a <form>'s named inputs into payload on submit — the same data-flv-* convention the SSR runtime uses, so one .fitzv targets both.

The form is <form data-flv-submit="add"> with <input name="text" data-flv-clear>; the handler is if (payload.has("text")) { items.push(payload["text"]) }. Type an item, press Add, and the input clears.

If you see this text but no widget above, the WASM bundle failed to load (check the DevTools console) or the page was opened over file://. ES modules require an HTTP origin — serve with python -m http.server 8000.
