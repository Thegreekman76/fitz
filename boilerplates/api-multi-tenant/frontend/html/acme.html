🔴 Acme Corp

Tenant Acme. Sus datos viven en el schema Postgres acme. El backend Fitz expone los handlers GET /acme/products y POST /acme/products que emiten SQL contra "acme"."products".

Enfoque A en acción: el ORM type AcmeProduct se define con @table("acme.products"). El método AcmeProduct.all(conn) compila a SELECT "id","name","price","created_at" FROM "acme"."products" — qualified al schema correcto automáticamente. Lo mismo para .insert, .where, etc.
