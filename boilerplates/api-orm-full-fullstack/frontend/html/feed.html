Feed realtime desconectado

El endpoint WS /feed es auth-protected (el @authenticated valida el JWT antes del upgrade HTTP). El broadcast es simétrico — todos los conectados ven los mensajes, incluido el emisor (convención Socket.IO/Phoenix). El token JWT viaja como ?token=<jwt> y nginx lo inyecta como header Authorization: Bearer ... antes de hacer el proxy al backend.
