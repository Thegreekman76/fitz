🏔️ Fitz API — frontend demo (CORS)

Cross-origin setup: este HTML corre en http://localhost:8080 (nginx alpine). La API Fitz corre en http://localhost:3000. Origins distintos → el browser hace preflight OPTIONS antes de cada POST/GET con headers custom. La API responde con Access-Control-Allow-Origin: http://localhost:8080 declarado en cada handler con @middleware(cors({...})).

1. Endpoint público: GET /items

Sin auth — el frontend puede pedirlo siempre. CORS habilitado.

(click el botón)

2. Login: POST /login

Devuelve un JWT bearer token. Credenciales hardcoded del boilerplate:

  • email: ada@example.com
  • password: secret-ada-123
(click el botón)

3. Endpoint protegido: GET /me

Requiere Authorization: Bearer <token>. El token del login va a localStorage; el botón lo lee de ahí.

(click el botón)
